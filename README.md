# amerganim/tap

Homebrew tap for [Amader Bangla Keyboard for macOS](https://github.com/amerganim/MacOSBanglaKeyboard) — a free phonetic Bangla keyboard.

```bash
brew install --cask amerganim/tap/amader-bangla-keyboard
```

Then add it once: System Settings → Keyboard → Input Sources → Edit… → + → Bangla → **Amader Bangla Keyboard**.

Update: `brew upgrade --cask amader-bangla-keyboard` · Remove: `brew uninstall --cask amader-bangla-keyboard`
